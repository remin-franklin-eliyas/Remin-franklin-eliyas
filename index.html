What I have built

📦 Published on PyPI — v0.1.1

PromptHub — Version Control for AI Prompts

Developer tool that treats prompts as first-class engineering artifacts. git diff tells you line 3 changed — PromptHub tells you the meaning changed. Semantic diffing via cosine distance on sentence embeddings, structural change detection (tone, format, reasoning, role), and behavioural regression testing by running both versions through a local LLM and comparing outputs. Fully local: SQLite storage, Ollama for inference, no API costs.
